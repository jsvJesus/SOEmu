# SOEmu MariaDB

По умолчанию сервер подключается к `root@127.0.0.1:3307` и использует базу
`soemu`. База и таблицы `accounts`/`characters` создаются автоматически из
`server/schema.sql`.

Пароль не хранится в репозитории и не записывается в лог. Если переменная
`SOEMU_DB_PASSWORD` отсутствует, сервер безопасно запросит пароль при запуске.

```powershell
$env:SOEMU_DB_PASSWORD = "ваш локальный пароль"
.\RUN_EMULATOR.bat
```

Доступные настройки: `SOEMU_DB_HOST`, `SOEMU_DB_PORT`, `SOEMU_DB_USER`,
`SOEMU_DB_NAME` или параметры `--db-host`, `--db-port`, `--db-user`,
`--db-name`.

Первый вход с новым логином автоматически создаёт аккаунт. Последующие входы
требуют тот же пароль. Пароли сохраняются как salted `scrypt`, а не открытым
текстом.

Реализованные штатные функции клиента:

- список персонажей аккаунта;
- проверка уникальности и правил имени;
- создание с сохранением выбранной внешности;
- отложенное на 7 дней удаление и штатное восстановление;
- сохранение обучения, последней карты и позиции.

Выбор группировки не добавлен: клиентский `createNewAvatar` этой версии
передаёт только имя и `PACKED_AVATAR_MODEL`.
